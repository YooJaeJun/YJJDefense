## 2026-11-16 ~ 17 · 01 프로토타입
1. **컨셉** — 킹덤러쉬식 길 따라 오는 타워 디펜스 + 스펠 디스크식 룬 조합. 판을 거듭할수록 룬·병졸을 모아 조합 경우의 수가 늘어난다.
   - 그림체: 냥코 대전쟁처럼 귀엽지만 엉뚱한 — 굵은 먹선, 흰 몸통, 점 눈, 멍한 표정.
2. **스펠 조합** — 디스크 3개 × 칸 2개에 룬을 꽂는다. 원소 6(불·얼음·물·번개·독·바람) + 형태 3(폭발·연쇄·분열) = 조합 45가지.
   - 다른 원소 둘 → 반응 15가지 (불+얼음 증발, 물+번개 감전, 얼음+물 빙결, 번개+바람 뇌운…). 같은 원소 둘 → 강화.
   - 따로 쏴도 반응: 먼저 맞은 원소가 적에게 묻어 있다가 다른 원소가 닿으면 터진다 (정령 제단 타워도 원소를 묻힌다).
3. **수집 메타** — 한 판 끝나면 수집 점수(버틴 웨이브, 승리, 별, 새로 써 본 조합) → 윈드볼 → 마법사 탑 → 포이즌볼 → 연쇄 → 정령 제단 → 분열 순으로 해금. 가방에는 룬 5개, 병졸 4종만 들고 나간다. 깨면 다음 도전 단계(몬스터 체력 +30%씩).
4. **기술** — 게임 규칙은 UObject 없는 순수 C++ 시뮬레이션(60Hz 고정 스텝, 결정적). 화면은 Canvas로 전부 그림. 아트 84장·효과음 17개를 파이썬으로 직접 생성 (외부 소스 없음).
   - 검증: 자동화 테스트 5개(조합 규칙, 반응, 타워, 한 판 전체+밸런스, 수집), 봇 오토플레이 스모크, Slate 입력 주입 UI 테스트 19단계.
   - 밸런스 기록(봇): 스펠 쓰면 1단계 목숨 20 그대로 승리, 스펠 없이는 9웨이브에서 패배 → "스펠 조합이 핵심"이 수치로 확인됨.
   - 삽질: 배경 나무 잎이 길을 덮어 몬스터가 나무 위를 걷는 것처럼 보임 → 길에서 잎 높이까지 떨어뜨려 배치. 첫 테스트 땐 궁수가 도깨비를 못 잡음 → 타워 화력 상향.
5. **피드백 반영** — "타워 자리가 더 명확해야" → 회색 돌 받침 + 망치 표지판, 지을 돈이 있으면 노랗게 숨 쉬는 점선 고리.
   - 소재: `Footage/01_Prototype` (준비·전투·결과·UI 테스트 스크린샷)

   - 웨이브 툴팁에 특수 능력 표시 ("코코넛 형님 x10 (쪼개짐)").
3. **봇·테스트** — 봇이 지도마다 길을 많이 덮는 자리부터 짓도록 일반화. 자동화 테스트 7개(지도별 한 판, 쪼개짐·면역 포함) 통과.
   - 삽질: 펭귄 면역 테스트가 계속 실패 → 알고 보니 스펠 공이 0.7초 날아가는데 0.4초만 기다리고 있었음. 빠른 몹은 공이 날아가는 동안 도망가서 앞을 노려야 맞는다.

   - 소재: `Footage/02_Maps_Monsters` (지도별 전투·준비·결과 스크린샷, 몬스터 시트)
